# Tips:
1. commnent and uncomment block
 - Comment
    + Ctrl + V, select the block you want to comment
    + Shift + i => insert a character
    + Esc
 - Un-comment
    + Ctrl + V,
    + d or x
    + Esc
2. vim git gutter
    + Refresh in 2 second
    + With doc: using <leader>hp for preview, <leader>hu for undo
3. lsp and cmp
